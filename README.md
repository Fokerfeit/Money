Money: A Simple Guide to the People's Ledger
What is Money?
Money is a decentralized, eco-friendly currency that doesn't require mining, blockchain, or energy-intensive systems. It runs on smartphones. It is validated by people. It belongs to everyone.
The Philosophy
- No pre-mine
- No CEO
- No hidden rules
- No elite validators
- No coins given to insiders

Just people. Just phones. Just Money.
How It Works
1. Send a Transaction
   - You open the Money app
   - You send MONEY to someone

2. Swarm Validation Begins
   - The transaction is broadcast to a group of randomly selected smartphones
   - Each phone verifies:
     - The signature is valid
     - The sender has enough balance
     - The transaction has not been seen before

3. Consensus via Signatures
   - Once a threshold number of phones validate it (e.g. 500+), the transaction is considered confirmed
   - The state of the ledger updates for all

4. Ledger Sync
   - Every phone holds a shard of the current state
   - Syncs happen via a lightweight gossip protocol with Merkle proof integrity
Privacy
Money uses full privacy by default. No one can see who sent what to whom. Even validators can’t see the real amounts.
Supply
- Starts at 1,000,000 MONEY
- A foundation wallet distributes 500 MONEY to each of the first 2,000 users
- After 1 million users, 1 MONEY is given per new verified user
- No inflation unless the people grow
- Verified user = 1 phone, 1 IP, helping validate
- Users who disconnect face a cooldown sync delay of 10 minutes
New: Lightweight DAG Ledger
Instead of blocks and proof-of-work, Money uses a simplified Directed Acyclic Graph (DAG) inspired ledger:
- Each transaction points to a few others before it, creating a web of confirmations
- Phones validate new transactions by checking signatures and confirming ancestry
- There’s no mining, no central ordering, and no need for SHA-256 style difficulty
- Security comes from the redundancy of thousands of smartphones validating and syncing together

This keeps it energy-efficient, fast, and truly decentralized.
Distributed Ledger History
Each smartphone stores a **shard** of the ledger history:
- No phone stores everything
- Together, phones reconstruct the full transaction record
- The system is resilient to failures and protects user storage and bandwidth
